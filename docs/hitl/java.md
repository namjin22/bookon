## AI 오류와 수정

Oracle에서 빈 출판사가 NULL로 반환돼 도서 수정 테스트가 NullPointerException으로 실패했다. BookDAO에서 NULL을 허용하도록 수정했고, 전체 25항목이 재실행에서 통과했다.
