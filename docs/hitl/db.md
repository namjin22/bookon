## 도서 분류번호(KDC) 확인 기록

`BOOK_ID`는 `NNN-NNN` 형식이다. 앞 3자리는 한국십진분류(KDC) 분류번호, 뒤 3자리는 같은 분류 안의 일련번호(폐기된 도서의 번호도 다시 쓰지 않음)로 우리가 직접 매긴 것이다. 팀장 지시대로 AI가 준 분류번호를 그대로 믿지 않고 확인했다.

- 확인하지 못한 이유: 서울도서관·세종도서관은 자동 조회가 막혀 있고(robots 제한), 국립중앙도서관 상세 페이지는 이 환경에서 직접 열 수 없었다. 우회하지 않았다.
