## 담당 기능

- Oracle 11g XE 프로젝트 전용 계정 `bookon` 생성
- 테이블·시퀀스·제약조건 생성 (`TBL_BOOK`, `TBL_STUDENT`, `TBL_LOAN` / `SEQ_STUDENT`, `SEQ_LOAN`)
- v2 규칙 반영 (2026-11-16): 도서 코드 `NNN-NNN`(십진분류 번호 + 일련번호, `SEQ_BOOK` 삭제), 연체 반납 시 대출 정지(`TBL_STUDENT.PENALTY_END_DATE`), 학생당 최대 3권
- 샘플 데이터 입력 (학생 8명, 도서 18권, 대출 11건)
- 대출·반납 SQL (`03_loan_return.sql`)
- 학생 관리 Java (`StudentDAO`, `StudentServlet`): 등록·수정·검색·삭제(미반납 대출이 있으면 막고 없으면 `USE_YN='N'`), 학번 중복은 `errors.studentNo`, v2 필드(`penaltyEndDate`, `penalized`, `loanCount`, `overdueCount`)

## 도서 분류번호(KDC) 확인 기록
